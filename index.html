Faith Companion · Sync

Cloud Sync Setup

This connects the app to a free database you create and control (Supabase), so your data syncs reliably between your phone and browser instead of relying on this chat's storage. Takes about 5 minutes, one time.

One-time setup (do this on a computer)

  1. Go to supabase.com and create a free account and a new project.
  2. Once it's created, open the SQL Editor and run this, then click Run: 
    create table faith_companion (
  sync_code text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table faith_companion enable row level security;
create policy "allow anon access"
on faith_companion for all
using (true) with check (true);
  3. Go to Project Settings → API. Copy the Project URL and the anon public key into the fields below.
Supabase Project URL Supabase anon public key Sync Code (same on every device)

Keep your Sync Code private — anyone with your Project URL, anon key, and this code could read or write your data. Use the same three values on every device you want synced.
